**FreeTools.run** is a set of fast, practical online tools: formatters, encoders and decoders, converters, image and PDF utilities, viewers and generators. **Open and use it, privacy-first, with processing kept in your browser wherever possible (no upload).** It is built for the everyday firefighting of developers, designers and operators.

- **Website**: https://freetools.run
- **All tools**: https://freetools.run
- **Blog / guides**: https://freetools.run/blog
- **RSS**: https://freetools.run/rss.xml
- **GitHub**: https://github.com/xiaokeaijourney/FreeTools.run

---

## Why FreeTools.run

- **Open and use.** No install, sign-up or login.
- **Privacy-first.** Formatting, conversion and generation run in the browser wherever possible; files are not uploaded to a server.
- **One domain for high-frequency tasks.** 56 tools grouped under Formatter, Converter, Image, PDF, Generator and more.
- **Kept current.** The registry and routes come from one configuration, so a new tool appears on the home page, category pages and sitemap together.

---

## What you can do

- **Log and API debugging**: format JSON, SQL and XML; convert cURL to code; decode JWTs
- **Security and compatibility**: encode or decode Base64 and URLs; convert Unix timestamps
- **Images and assets**: convert HEIC, SVG, JPG, PNG and WebP; compress, crop, resize; generate favicons
- **Documents and collaboration**: preview Markdown and Mermaid; convert HTML to Markdown; diff text; merge, split and compress PDFs
- **Everyday utilities**: generate UUIDs, passwords, hashes, QR codes and Cron expressions

## Local development

Requires Node.js >= 22.12.0.

```bash
npm install
npm run dev        # Vite + local Worker at http://localhost:3000
npm run build      # writes dist/ (client + server)
npm run preview    # preview the build at http://localhost:8788
npm run typecheck
npm run lint
npm run test:unit  # registry ↔ route contract
npm run test:e2e   # Playwright; build first
npm run deploy     # build and wrangler deploy
```

`README.md` is generated from `README.md.template` and `src/config/tools-data.ts`; do not edit the generated block by hand:

```bash
python3 scripts/generate_readme.py
```

Stack: TanStack Start (React SSR + Vite), TypeScript, Tailwind CSS v4, shadcn/ui (Radix) and Monaco Editor, deployed to Cloudflare Workers via `@cloudflare/vite-plugin`.

## Privacy

- **Local processing first.** Formatting, conversion and generation run in the browser wherever possible.
- **No login required.** Most tools need no account.
- **Query tools are the exception.** IP lookup and similar tools need a network request; the page states what is sent.
- **Files stay on your device.** Pure front-end tools read local files and hand the result back as a download.

---

## FAQ

**Are the tools free?**
Yes. The goal is to keep the core tools free and available.

**Can I use them offline?**
Most pure front-end tools keep working on a poor connection. Query-based tools still need the network.

**Do I need to install anything or sign up?**
No. Open the page and use it; there is no installer, extension or account requirement.

**How do I report a bug or suggest a tool?**
Open an issue in this repository with the scenario, the expected input and output, and sample data.
